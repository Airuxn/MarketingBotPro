# MarketingBot Pro - Quick Start Guide

## 🚀 Get Started in 3 Steps

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Start the App
```bash
npm run dev
```

### Step 3: Configure
1. Open http://localhost:3000
2. Go to **Settings**
3. **1. Add API Key** - Add your Google Gemini API key (get one at https://aistudio.google.com/app/apikey)
4. **2. Business Info** - Fill in your business name, type, and target audience
5. **3. Connect Socials** - Connect social media accounts (optional, but recommended for learning)

## ✨ What You Can Do

### 1. Create AI Content
- Click **"Create Content"** on the dashboard
- Choose content type (Post, Email, Ad)
- Enter what you want to create
- Get AI-generated content instantly!

### 2. Schedule Social Media Posts
- Create content or use existing drafts
- Click **"Schedule Posts"**
- Pick date and time
- Your posts are ready to go!

### 3. Manage Leads
- Click **"Manage Leads"**
- Add new potential clients
- Track their status (new → contacted → qualified → converted)

### 4. Email Campaigns
- Click **"Email Campaigns"**
- Create campaigns with AI
- Select recipients from your leads
- Send automated emails

### 5. View Analytics
- Click **"Analytics"** to see:
  - Posts created and scheduled
  - Emails sent
  - Leads captured
  - Conversion rates

## 📱 Install as App (PWA)

1. Open the app in your browser
2. Look for the "Install" or "Add to Home Screen" prompt
3. Click it to install
4. Now it works like a native app!

## 💡 Pro Tips

- **Better AI Content**: Fill in detailed business info in Settings
- **Save Time**: Use AI to generate multiple variations
- **Track Everything**: Add all leads to see your growth
- **Schedule Ahead**: Plan your content for the week
